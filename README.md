### 💬 TeaTalks

An anonymous platform where students can post, comment, vote in polls, report content, and get notifications — without showing their real identity.

**My Contribution:**

- Set up login and role-based auth

- Integrated AI for toxicity detection in posts

**Cool thing about it:** It uses a mix of rule-based NLP and AI moderation together, with a fallback system if one fails.

**Tech Used:** `Node.js` `Express.js` `MongoDB` `Mongoose` `JWT` `Groq`

A team project that helps artisans (craftspeople) put their products online. The platform uses AI to make the process easier for people who aren't tech-savvy.

**My Contribution:**
